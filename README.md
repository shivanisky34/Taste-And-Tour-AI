# 🍜 AI-Driven Local Food & Culture Exploration Guide

An intelligent recommendation and mapping assistant that matches user taste preferences with authentic local food spots and cultural landmarks using Python, Flask, and AI.

---

## 🛠️ Tech Stack

* **Programming Language:** Python
* **Backend Framework:** Flask (REST API)
* **Generative AI / Maps:** Google Gemini API / Maps Integration
* **Tools & IDE:** VS Code, Git, GitHub

---

## ✨ Key Features

* **🍲 Personalized Food Recommendations:** Suggests authentic local food spots based on individual user taste preferences.
* **🏛️ Cultural Landmark Mapping:** Highlights nearby historical sites, museums, and cultural points of interest.
* **📍 Smart Itinerary Integration:** Combines culinary stops with sightseeing routes seamlessly.
* **⚡ Instant AI Guide:** Interactive chat assistant to answer queries about local cuisines and heritage.
